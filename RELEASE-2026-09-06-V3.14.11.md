# TimeGrid v3.14.11 — state-aware picker spacing

Status: Deployed. The user reported that an Area-only
Todo classification retained excessive trailing space on mobile and requested a
shared root repair for mobile and desktop. D-027 authorizes deployment after
verification.

## Cause and repair

The combined Area / Activity picker did not expose whether it rendered an empty
placeholder, Area only, or Area plus Activity. All states therefore inherited the
same symmetric 12px padding and 6px content-to-caret gap. Mobile added a separate
72px minimum, so a short Area label could not shrink to its content even after the
v3.14.10 intrinsic grid repair.

The shared picker now publishes its semantic value kind on every refresh. The
Area-only state uses 10px start padding, 8px end padding and a 4px caret gap on
both desktop and mobile. Mobile no longer imposes a state-independent minimum;
the existing intrinsic grid and genuine viewport maximum remain. Empty and
Area-plus-Activity states retain their prior spacing, and the accepted one-line
composer, interaction and catalog semantics are unchanged.

## Verification

- The new production-bootstrap regression failed on v3.14.10 at 390px because
  the Area-only caret had more than 9px of trailing space.
- On v3.14.11, both 390px and 1280px renders measured an Area-only width of
  58.97px, 9px border-inclusive trailing inset and 24px total non-text chrome.
  The Area text and complete picker content were not clipped.
- The existing `공부 · 정치와 법` mobile case still renders completely on one
  row with zero horizontal overflow. Resting mobile and desktop screenshots were
  inspected with transient autocomplete/picker layers closed.
- All four production-bootstrap contexts passed at 390px and 1280px with GSAP
  enabled and deliberately unavailable, including local exact Start/Stop,
  persistence, worker activation/control and offline shell reload.
- All 28 Node test programs passed. Extracted inline script and worker syntax,
  release identity, static selector contracts, live SRI, U+FFFD=0 and scoped diff
  checks passed.
- Native iPhone/WebKit and authenticated multi-device E2E were not executed.
