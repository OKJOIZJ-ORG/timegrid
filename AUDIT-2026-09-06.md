## Reproduced failures and repairs

| Area | Before | Repair and discriminating evidence |
|---|---|---|
| Exact log import | Two disjoint ten-second events in one display minute became one event. | Timestamp-based clipping preserves both, event IDs, exact bounds and supplied midnight fragments. Actual overlap clips only covered time; missing fragments are not rebuilt. |
| Log identity | Explicit same-title Todos collapsed and overwrote completion; event export omitted linked IDs. | Explicit Todo/routine IDs and event links round-trip independently. Only unambiguous legacy labels may resolve by name. |
| Backup merge | A plan-only day was replaced; additions to a measured day were ignored. | Existing IDs retain current fields; missing IDs and immutable mutation records are unioned. Independent overlapping measurements reject the whole merge before mutation rather than double-counting or choosing a winner. |
| Routine editor | Normalization replaced definition objects; subsequent UI callbacks changed detached objects, including deletion. | Each action resolves the current ID. Delayed deletion captures current fields; undo cannot overwrite a same-ID row. Four actual-callback cases failed before repair and pass afterward. |
| Routine identity | A new same-name definition inherited the old definition's completed/measured instance. | Semantic legacy adoption excludes explicit different definition IDs; old history survives separately and the new instance starts unchecked. |
| Input and motion | A completed view entrance retained its animation class; switching from keyboard to pointer restarted it before click, moving the target. | Remove completed/cancelled entrance ownership while preserving intentional transition timing. The regression retains the expected first-click action. |
| Account lifecycle | Late heartbeat, initial reads, listeners and transaction responses could enter another login's state. | UID plus login generation fences asynchronous boundaries, including same-UID relogin. Eight deferred lifecycle cases cover data/base/outbox, acknowledgments and pre-publication cancellation. Already committed server transactions remain canonical. |
| Cache ownership | Worker activation deleted other apps' caches on the shared origin; global cache reads crossed ownership. | Only stale TimeGrid caches are deleted; reads use this release's shell/runtime caches. |
| Cache lifetime | Unobserved cache writes could be terminated or reject after a successful network response. | Awaited writes remain within response lifetime; storage errors preserve the usable response. |
| Safe update | Hidden update controls accepted focus/actions; another tab's activation or a delayed fallback reloaded active/pending measurement. | Hidden banner is inert, inactive clicks are no-ops, and both reload paths wait for a safe state and an explicit request. First installation is distinguished from an update. |

## Verification

The original 23 Node programs passed; the sandbox-blocked live CDN SRI check
passed after network access was available. Existing passing tests did not cover
the newly reproduced failure paths. The final integrated run passed all 129
Node checks across 27 test programs, including live CDN SRI, extracted inline/SW
syntax and U+FFFD=0. The later legacy backup regression also verifies multiple
ID-less definitions receive stable distinct identities before union.

Chromium acceptance passed Todo date actions, Stop acknowledgment completion,
routine sequential editing/deletion/undo and PWA update focus/reload lifecycles.
Planner/Stop scenarios cover 390px and 1280px; catalog touch/keyboard/reduced-motion
scenarios cover 320px, 390px and 1280px. Tests exercised ordinary and explicitly
GSAP-disabled fixture configurations; those labels alone do not prove CDN
availability. Stable routine screenshots were inspected at 390px and 1280px.

`real-bootstrap.browser.mjs` additionally passed four fresh 390px/1280px browser
contexts against unchanged production HTML/assets on an isolated localhost
origin. It verifies actual local Start/Stop exact endpoints and persistence,
Service Worker activation/control, shell cache identity and offline reload with
no local asset failures or horizontal overflow. GSAP-enabled cases execute the
production CDN bytes after Node-side SHA384 verification; browser transport is
fulfilled with those bytes and anonymous CORS. Disabled cases explicitly block
GSAP. Firebase requests are deliberately blocked to keep this a guest/local
test; real authenticated sync and direct browser-to-CDN availability are not
established by this test.

New tests: `import-integrity.test.mjs`, `routine-editor.test.mjs`,
`sync-session.test.mjs`, `pwa-lifecycle.test.mjs`,
`routine-editor.browser.mjs`, `pwa-update.browser.mjs`, and
`real-bootstrap.browser.mjs`.
Existing extraction harnesses include the new sync-session helper without
weakening assertions. Browser tests accept `TIMEGRID_TEST_URL`; the synthetic
server accepts `PORT`, avoiding interference with an unrelated process on 8765.

No CSS selectors or layout rules changed. Render checks still cover actual
generated controls. Firestore rules are unchanged: transaction/interleaving
tests and the local rules-contract checks are evidence, not an authenticated
multi-device production test or a new emulator deployment.
