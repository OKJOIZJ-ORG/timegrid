# TimeGrid v3.14.10 — content-sized mobile Todo classification

Status: Deployed. The user reported that the Todo
composer's Area / Activity label resized correctly on desktop but clipped on
mobile. D-027 authorizes deployment after verification.

## Cause and repair

The mobile-only rule replaced the shared intrinsic picker sizing with a 96px
flex basis and maximum. The picker's padding, separator, activity chip and caret
then competed inside that fixed box, so even ordinary labels could be clipped.
This was a layout ownership defect rather than a catalog-data or font defect.

The mobile composer now uses one grid row with `minmax(0,1fr) max-content auto`.
The title input owns the remaining width, the classification picker follows its
rendered Area / Activity label, and the Add action retains its fixed minimum.
The picker is bounded only at `min(48vw, 180px)` for genuinely long labels on a
small viewport. The accepted one-line `Todo input | area/activity | add` contract,
desktop layout, picker interaction and catalog semantics are preserved.

  composed content and caret all fit; input, picker and Add share one row; page
